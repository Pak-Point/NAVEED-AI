# Naveed AI Android — ابتدائی ورژن

یہ Android Studio project ہے؛ ابھی تیار شدہ APK نہیں۔

## شامل فیچرز
- اردو، سرائیکی اور English زبان منتخب کرنے کا اختیار
- وائس ان پٹ (Android Speech Recognizer، فون/سروس کی دستیابی کے مطابق)
- ٹچ سے حکم لکھنا اور چلانا
- WhatsApp، YouTube، Facebook اور Instagram کھولنا
- اجازت ملنے پر ٹارچ آن/آف
- وقت بتانا اور Clock ایپ میں الارم سیٹ کرنے کی سہولت

## APK حاصل کرنا
GitHub میں Actions کھولیں اور **Build Naveed AI Android APK** workflow چلائیں۔ کامیاب build کے بعد Artifacts میں **Naveed-AI-debug-apk** ملے گا۔

## ابھی شامل نہیں
Gemini AI chat، ہمیشہ سننے والا Hey Naveed wake word، خودکار کال یا پیغام بھیجنا، Wi-Fi/Bluetooth کی مکمل سیٹنگ کنٹرول۔ ان کے لیے الگ محفوظ implementation اور Android permissions درکار ہوں گی۔

مائیکروفون/کیمرہ کی اجازت صرف فیچر استعمال کرتے وقت مانگی جاتی ہے۔ Android اور فون ساز کی پابندیوں کے باعث ہر کام خودکار طور پر ممکن نہیں۔
